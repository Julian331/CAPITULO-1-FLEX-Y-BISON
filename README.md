# CAPITULO-1-FLEX-Y-BISON
Este repositorio contiene el archivo Informe.pdf, en el cual se desarrollan los cinco (5) primeros ejemplos del Capítulo 1 del libro flex & bison, así como los seis (6) ejercicios propuestos en dicho capítulo.

- En el informe se documenta el proceso paso a paso de cada implementación, incluyendo:

- Construcción de los analizadores léxicos con Flex.

- Desarrollo del analizador sintáctico con Bison.

- Explicación de las modificaciones realizadas.

- Resultados obtenidos en cada ejecución.

- Casos de uso y pruebas realizadas para validar el funcionamiento.

- El objetivo es evidenciar la correcta implementación de los conceptos fundamentales de análisis léxico y sintáctico presentados en el capítulo.
